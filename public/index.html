how this works

new runs one investigation: a simulated human learner asks your tutor one scoped question at a time until it can explain the idea in its own words.

full does that, then the tutor picks 3 more related concepts to investigate — a small tour of the topic.

⤵ branch under any tutor answer re-investigates that answer more deeply, growing the tree. Every turn is two real model calls (~5–7¢).

Trees live in this browser. Use save .know.json to move one to another device or the CLI — the file format is identical.
